Use it on iPhone
1Tap Start Hunter. GitHub will create/open the Hunter Codespace from main.
2Wait for the Codespace build to finish. Hunter starts automatically on port 8501; you do not need to type terminal commands.
3When GitHub shows that port 8501 is available, tap Open in Browser. That opens the actual Hunter upload/prediction screen.
4Upload one Saturday Lotto video, set the pre-result cutoff, then tap Generate & lock prediction.
The previous launcher used one temporary Codespace address. Codespace addresses can change or expire, which is why that button could stop working. This page now uses GitHub's stable Codespaces launch flow instead.
Hunter will not randomly fill missing numbered identities. If the video cannot support a numbered Top-6, it reports insufficient identity evidence rather than fabricating numbers.
